# Setup checklist

The repository starts in SETUP_REVIEW_MODE. Publishing is blocked in both config and workflow environment.

Required later:
- Instagram professional account and supported Meta app
- META_ACCESS_TOKEN, INSTAGRAM_USER_ID
- META_GRAPH_API_VERSION repository variable (set only after checking current Meta docs)
- public R2/S3-compatible media hosting secrets and CDN base URL
- OPENAI_API_KEY for live research/generation

Never put secrets in files or logs. First approval phrase: APPROVE AUTOPUBLISH.
